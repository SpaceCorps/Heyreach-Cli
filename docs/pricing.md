## HeyReach Outreach Platform Subscriptions
The CLI interacts with the official HeyReach LinkedIn outreach platform ([heyreach.io](https://heyreach.io)). Platform subscription and API access are managed directly by HeyReach:
- **Free Trial**: Available for initial setup, sequence design, and account connection.
- **Platform Plans**: Monthly or annual subscriptions for agency and multi-account LinkedIn outreach.
- **API Access**: Access to the public HeyReach REST API via API key is included with supported subscription tiers.

For official subscription details and current plan features, visit [https://heyreach.io](https://heyreach.io).
